# Aplicativo 04 – Gerenciador de Tarefas

Aplicativo Ionic/Angular para cadastro e acompanhamento de tarefas com suporte a Capacitor, testes unitários e estilos tematizados.

## Recursos principais
- Estrutura Ionic com roteamento modular e páginas em `src/app/pages`.
- Integração Capacitor pronta para build mobile (`capacitor.config.ts`).
- Sistema de temas centralizado em `src/theme`.
- Ambiente configurado para testes Karma/Jasmine e linting via ESLint.

## Requisitos
- Node.js (>= 18 LTS)
- npm (>= 9)
- Ionic CLI `npm i -g @ionic/cli`
- Capacitor CLI `npm i -g @capacitor/cli`

## Instalação
````bash
npm install
